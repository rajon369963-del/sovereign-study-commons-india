# Support

Sovereign Study Commons India is an open educational repository. Please use the smallest public surface that matches your need so evidence defects stay easy to triage.

## Use an issue form for reproducible defects

Open the **Report bug, data-integrity, or provenance defect** form when you can provide a bounded reproduction plus show-your-work evidence for a repository bug, dataset/integrity problem, identity/deduplication failure, provenance/source-lineage defect, parity mismatch, or false demo-vs-real claim.

For proposing a public educational YouTube playlist or video, use the existing **Propose Lecture Playlist / Video for Review** form. Submission is a review request only; it does not promise automatic ingestion or republication.

## Questions and general help

Before opening an issue, check the README and CONTRIBUTING guidance. If you do not yet have a reproducible defect, do not fabricate logs or force a bug report. Keep the question until you can point to a concrete repository artifact, documented behavior, or public evidence. GitHub Discussions is intentionally not enabled at the current verified support volume.

## Privacy and content safety

Do not post passwords, API keys, access tokens, private learner telemetry, personal contact details, medical or other sensitive information, or copyrighted bulk question/transcript dumps. Redact logs and screenshots. Share only the minimum evidence needed to reproduce or falsify the claim.

If a report concerns a security vulnerability that should not be public, follow SECURITY.md instead of opening a public issue.

## Truthfulness boundary

A submitted issue, accepted fix, green CI run, or demo does not by itself prove deployment, GitHub↔Hugging Face↔Drive parity, provenance/license validity, pedagogical efficacy, or learner-score gains. Numerical learner gains remain unvalidated until real cohort evidence exists.
